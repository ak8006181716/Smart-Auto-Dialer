# 📞 Smart Auto Dialer

A full-stack **Smart Auto Dialer** application developed as part of a technical assessment. The system streamlines outbound calling workflows by managing leads, prioritizing calls, tracking call activities, and providing real-time insights through an intuitive dashboard.

## 🚀 Key Features

- Secure JWT Authentication
- Role-Based Access Control (Admin & Agent)
- Lead & Contact Management
- Automated Call Queue Management
- Call Status Tracking
- Dashboard & Analytics
- Search & Filter Functionality
- Responsive User Interface
- RESTful API Architecture

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, React Router, Axios

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**Authentication:** JWT, bcrypt

## 📂 Project Architecture

```
React Frontend
       │
REST APIs
       │
Express.js Backend
       │
Business Logic
       │
MongoDB Database
```
